**Keep them safe, tell them the truth, help them grow, and let them choose.**

That one line is the whole directive. The full text — about 1,140 words — adds who counts as
"them", seven principles in priority order, a six-question decision procedure you can actually run
in the middle of a task, what the directive does and does not license, and worked examples.

This is the first tagged release. Nothing in it is new; the point of the tag is that the directive
now has a version you can cite, pin, and diff against.

## What you get

- **The directive**, at `.claude/skills/prime-directive/SKILL.md`. Source hash `448faa3c1844`.
- **Always-on delivery into ten locations** — Claude Code / Cowork, Codex, Gemini CLI, Copilot,
  Cursor, Windsurf, Cline / Roo Code, and the `AGENTS.md` convention shared by Aider, Zed, Warp,
  Junie, Devin, OpenCode, Amp and Jules. One source, rendered into each tool's own format, every
  copy stamped with a hash of the source.
- **A way to prove it is on.** `scripts/doctor.sh` reports every known location and exits non-zero
  if anything is stale, hand-edited, or missing. It runs in CI here for exactly that reason.
- **Evidence.** `examples/` holds twenty paired runs — five scenarios, with and without the
  directive, on four models across two tools — with the raw captures committed beside the rendered
  transcripts. Including the scenarios where the directive changed nothing, and the one capture
  that came out worse with it than without.

## Try it

```sh
git clone --branch v0.1.0 https://github.com/12529572-Canada-Inc/prime-directive.git
cd prime-directive
./install.sh          # every agent on this machine
scripts/doctor.sh     # prove it is on
```

## Versioning from here

[`VERSIONING.md`](../../VERSIONING.md) sets the rule, and it is about behaviour rather than diffs:
if a change could make an agent act differently in a case the previous version already handled,
it is a major bump — including a wording change that resolves an ambiguity. Wording that makes the
same instruction easier to read is a minor. Where it is too close to call, `examples/` is the
tiebreaker, and an unaffordable tiebreaker means major.

`0.x` means the substance is still settling. Majors will land.

## What this release does not claim

A context file is advice to a model, not enforcement. Being loaded is not the same as being obeyed:
a tool can rank its own system prompt above it, truncate it, or ignore it. Pinning this tag fixes
the words an agent reads. It does not fix what the agent does with them.
